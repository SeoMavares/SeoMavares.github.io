LinguaLens

Traductor para Android que funciona como app y también como pantalla de inicio del teléfono. Traduce sin conexión y sin clave de API, porque lleva un diccionario dentro.

  • Kotlin
  • Jetpack Compose
  • ML Kit
  • Room
Con conexión DeepSeek → Gemini → ML Kit → diccionario
Sin conexión ML Kit → diccionario
  • ✓Sin conexión en los idiomas que tienen paquete instalado, sin clave de API ni servicios externos.
  • ✓Cámara, voz y documentos con OCR propio y salida en PDF, Word o texto.
  • ✓Launcher propio que sustituye la pantalla de inicio, con panel lateral y notificación fija.
  • ✓Panel de control en Node.js para cambiar claves y modos sin recompilar el APK.

miwayomi

Servidor que ejecuta en el ordenador las extensiones de Android de Tachiyomi y Aniyomi, sin emulador y sin teléfono, y las publica como API y como interfaz web.

  • Kotlin
  • Ktor
  • JVM
  • Docker
docker compose up -d
listo en el navegador
  • ✓Lo usan otras personas: hay forks y peticiones abiertas desde fuera de mi cuenta.
  • ✓Carga extensiones convirtiendo el APK y reparando el bytecode.
  • ✓Vídeo HLS y DASH con los manifiestos reescritos.
